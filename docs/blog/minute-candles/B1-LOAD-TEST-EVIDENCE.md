## 해석 한계와 다음 시험

- B0에는 같은 수준의 원시 결과와 환경 manifest가 없어 B1과의 차이를 성능 회귀로 단정하지 않는다.
- VU는 실제 사용자 수가 아니며 20초 고정 부하는 운영 트래픽 분포를 재현하지 않는다.
- 후속 시험 또는 B2는 5회 반복, 별도 부하 발생기, CPU·heap·GC·Hikari·DB 지표, 10분 단계 부하와 8시간 soak를 포함한다.
- 포화 원인이 확인되기 전에는 Redis, DB replica, pool 확대 같은 해결책을 미리 선택하지 않는다.
